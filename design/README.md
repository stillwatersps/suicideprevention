# Design references

The supplied homepage is saved as `homepage.svg`. It shows the project's earlier
name, Stillwater; the website now uses Tidelight.
The exact pasted text is preserved in `source/homepage-original.txt`.
Leading nonbreaking spaces in the pasted markup were converted to normal spaces
in `homepage.svg` so the embedded style rules render consistently. Displayed
text, geometry, and colors were preserved.

## What it covers

- A desktop homepage at 1440 by 1100.
- Header navigation, landscape hero, three support actions, a trust row, three
  resource cards, and a closing banner.
- A warm cream background, forest green and plum accents, serif headings, and
  sans-serif body text.

This is a static visual reference; its buttons and links do not work. The phone
layout and the destination pages were built directly in the website rather than
drawn here. `notes/DESIGN.md` lists where the website differs from this drawing.
The website treats the drawing's round-the-clock and counselor wording as describing
the 988 Lifeline, and names that service instead of implying Tidelight provides it.
Founders to confirm.

Design assets are shared through GitHub alongside the project notes and code.
