# Design references

The supplied Stillwater homepage is saved as `homepage.svg`.
The exact pasted text is preserved in `source/homepage-original.txt`.
Leading nonbreaking spaces in the pasted markup were converted to normal spaces
in `homepage.svg` so the embedded style rules render consistently. Displayed
text, geometry, and colors were preserved.

## What it covers

- A desktop homepage at 1440 by 1100.
- Header navigation, landscape hero, three support actions, a trust row, three
  resource cards, and a closing banner.
- A warm cream background, forest green and plum accents, serif headings, and
  sans-serif body text.

The phone layout and destination pages remain to be designed. This is a static
visual reference; buttons and links are not functioning website controls.
Before implementation, confirm which service the round-the-clock availability
and counselor wording refers to, so the website describes its role accurately.

Design assets are shared through GitHub alongside the project notes and code.
