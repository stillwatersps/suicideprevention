# Task handoffs

Create one short Markdown note per task, with a distinctive filename such as
`yourname-home-screen.md`. Separate files reduce simultaneous edits to one log.

Include:

- Date and task owner
- Branch name
- What changed
- Important decisions
- What was checked, and any known issues
- What the next person needs to do

Keep passwords, access tokens, personal journals, and real user information out
of these notes. Use fictional examples for the prototype.
